# 실행 결과 기록

최종 프로그램을 실행한 뒤, 터미널에 나온 결과를 아래에 복사하세요.

====== 프로젝트 일정 관리기 ======
1. 할 일 목록 보기 (진행률 포함)
2. 새 할 일 추가하기
3. 할 일 완료 체크
4. 마감 임박 긴급 작업 확인
5. 할 일 삭제하기
6. 프로그램 종료
=================================
원하는 기능의 번호를 입력하세요: 2

--- 2. 새 할 일 추가하기 ---
할 일 이름을 입력하세요: 수학 수행평가
남은 기간(D-Day 숫자)을 입력하세요: 2
'수학 수행평가' 작업이 성공적으로 추가되었습니다!

실행할 때 사용한 입력값:


1. 메뉴 번호 '2' 입력 -> 작업명 '수학 수행평가', D-Day '2' 입력하여 새로운 할 일 등록
2. 메뉴 번호 '1' 입력 -> 등록된 목록과 진행률(0%) 확인
3. 메뉴 번호 '3' 입력 -> 완료 처리할 작업 번호 '1' 입력하여 완료 상태로 변경
4. 메뉴 번호 '1' 입력 -> 완료 여부가 Y로 바뀌고 진행률이 100%로 상승한 것 확인
5. 메뉴 번호 '6' 입력 -> 프로그램 정상 종료

결과가 내가 의도한 대로 나왔는지 설명:

새로운 할 일을 추가했을 때 2차원 리스트에 정상적으로 데이터가 누적되었으며, 완료 체크를 했을 때 
해당 인덱스의 완료 여부 값이 "N"에서 "Y"로 정확하게 변경되었습니다. 또한, 전체 작업 중 완료된 작업의 
비율을 계산하여 실시간으로 진행률 게이지 바가 차오르는 것과프로그램을 종료했을 때 
루프를 빠져나와 안전하게 닫히는 것까지 모두 초기 기획 의도와 완벽하게 일치하게 작동하였습니다.
